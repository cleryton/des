# Assistente Pessoal com IA

Projeto que conecta um script Python à API da OpenAI e utiliza PostgreSQL para armazenar tarefas, notas e histórico de conversas.

## Requisitos
- Python 3.8+
- PostgreSQL (com pgAdmin ou acesso via terminal)
- Chave da API da OpenAI (https://platform.openai.com/api-keys)
